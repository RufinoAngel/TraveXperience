Esta carpeta contiene todos los recursos relacionados con el diseño, implementación y administración de las bases de datos utilizadas en el proyecto. Se organiza en dos categorías principales: bases de datos SQL y NoSQL, permitiendo almacenar y gestionar la información de acuerdo con los requerimientos del sistema.
