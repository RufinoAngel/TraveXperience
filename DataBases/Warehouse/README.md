Esta carpeta contiene los recursos relacionados con el **Data Warehouse** del proyecto, incluyendo el **modelo dimensional** (hechos y dimensiones) utilizado para el análisis y la explotación de la información. Aquí se centraliza el diseño orientado a la consulta y análisis de datos, sirviendo como destino final del proceso ETL y como base para reportes, indicadores y tareas de extracción de conocimiento.
