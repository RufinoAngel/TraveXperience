Esta carpeta contiene los scripts y recursos relacionados con el proceso de **Extracción, Transformación y Carga (ETL)** de los datos utilizados en el proyecto. Aquí se centraliza la lógica encargada de tomar los datos desde sus fuentes originales, transformarlos según las reglas de negocio y del modelo de datos, y cargarlos hacia el Data Warehouse u otros destinos definidos por el sistema.
