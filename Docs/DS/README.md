# Design Specification - TraveXperience

## ¿Qué es?

`DS` contiene la documentación de diseño del proyecto **TraveXperience**. En esta sección se almacenan los artefactos que describen el comportamiento y la estructura del sistema, sirviendo como base para el desarrollo, las pruebas y el mantenimiento de la aplicación.

Incluye:

- Documento de especificación de casos de uso.
- Diagramas de casos de uso para Visitante, Usuario Registrado y Administrador.
- Diagramas de diseño que describen la interacción entre los actores y el sistema.
- Documentación utilizada como referencia para el desarrollo e implementación.

## Observaciones generales

- Los casos de uso deben mantenerse sincronizados con los requisitos funcionales y las reglas de negocio del proyecto.
- Cualquier modificación en el comportamiento del sistema debe reflejarse tanto en el documento de casos de uso como en sus diagramas correspondientes.
- Los diagramas elaborados en Draw.io deben actualizarse cada vez que se agreguen, modifiquen o eliminen funcionalidades para mantener la consistencia de la documentación.
